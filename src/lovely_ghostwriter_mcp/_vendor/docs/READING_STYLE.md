# READING_STYLE.md — 鑑定文のスタイルガイド（天使の自動筆記（ラブリーゴーストライター）: 1ページ目＝心理学レンズの鑑定／2ページ目＝予言詩）

鑑定文は「占術の結果の列挙」ではなく、**占術に心理学の用語を取り入れた、根拠のある啓蒙的な内容**にする。
読み手が「占いが当たった」ではなく「自分の心の動きが分かった」と持ち帰れることがゴール。

## 実装の場所（このガイドの正本はコード側）

| 何を | どこで |
|---|---|
| Claude への指示（作法・4層構造・禁止事項） | `uranai/reading.py` の `SYSTEM_PROMPT_BASE` |
| 使ってよい心理学概念（許可リスト・由来・一行定義） | `uranai/psych.py` の `CONCEPTS`（プロンプトに自動で埋め込まれる） |
| 出力の形（4層の各フィールドと字数の目安） | `schemas/reading.schema.json` |
| 生成後の機械検査（概念名・捏造・診断表現・固定文の重複） | `uranai/psych.py` の `check_style()`。不合格なら理由を添えて1回だけ出し直し、それでも不合格なら描画しない |
| 二層構造の明示（固定文） | `psych.FRAME_NOTE`（鑑定書・report.md に**1回だけ**印字） |
| 表示（4層の並べ方） | `uranai/templates/print.html.j2`・`digital.html.j2`・`reading.to_markdown()` |
| 予言詩の指示・単独生成プロンプト | `uranai/reading.py` の `POEM_STYLE_GUIDE`・`build_poem_prompt(job, calc)`・`poem_schema()` |
| 予言詩の検査 | `uranai/psych.py` の `check_poem(poem, job, calc)`（内訳: `check_poem_literary`＝助言調＋`check_poem_doom`＝災厄の断定、`check_poem_motifs`＝モチーフ・逐語・字数・形） |
| 予言詩の組版（p2 の1ページに収める） | `uranai/fit.py` の `POEM_LEVELS`（W0〜W6） |

このガイドを変えるときは、上のコードも合わせて変える（テスト: `tests/test_harness.py` の style 系、予言詩は `tests/test_prophecy_poem.py`・`tests/test_amendment16.py`）。

## 1. 二層構造

- **占いは自己理解のきっかけ（フレーム）**、**心理学は行動の根拠**。
- この一文は鑑定書の統合解釈の欄に、固定文として**1回だけ**出す。
  > この鑑定書では、占術を自己理解のきっかけ（フレーム）として、心理学の概念を行動の根拠として使っています。
- 生成する文章の中ではくり返さない（`check_style` が「フレーム」の語を検出したら不合格）。

## 2. 4層構造（4テーマ＋占ってほしいことへの回答）

仕事／恋愛／才能／金運の各テーマと回答は、次の4層で書く。

| 層 | フィールド | 内容 | 目安 |
|---|---|---|---|
| ① 占術の所見 | `finding` | calc.json に根拠を持つ所見。カード名・星・数などの値を文中に入れる。`basis` に根拠の占術と値 | テーマ75字／回答110字 |
| ② 心理学のレンズ | `concept` ＋ `lens` | 所見を名前のある心理学概念1つに翻訳し、1〜2文で解説 | 65字／80字 |
| ③ なぜそう言えるか（啓蒙の核） | `why` | 占いを外しても成り立つ心の機序を短く | 65字／80字 |
| ④ 具体的な一歩 | `step` | 小さく、やったか本人が確かめられる行動（回数・時間・場面）。従来の「おすすめの行動」はここに統合した | 30字／34字 |

印刷版とデジタル版の短縮用に `print_finding`（①の短縮）と `print_lens`（②と③をまとめた短縮）も作る。

### 例（形の見本。値は架空）

- ① 所見: 仕事のカードはワンドの9の正位置で、「最後のひと踏ん張り」を示します。
- ② 自己効力感｜「自分ならやれる」という見通しのこと。カードの粘りは、この見通しがあるときに出やすい姿です。
- ③ なぜ: 見通しは、小さな達成の記録から育ちます。「できた」を思い出せる材料があると、次も手が動きやすくなります。
- ④ 一歩: 今日やり終えたことを、寝る前に3行だけ書く。

## 3. 概念の選び方

- **許可リスト（`psych.CONCEPTS`）にある概念だけを使う**。表記ゆれ（例「if-thenプランニング」）は正式名に直す。リストにない名前は不合格。
- テーマごとに**1概念が基本**。4テーマで同じ概念をくり返さない。内容に合うものだけを選び、無理に詰め込まない。
- 統合解釈では、テーマとは別に**1〜2概念まで**（`integration.concepts`）。総評（`synthesis`）でそれに触れる。
- 当たっていると感じたときの注意として、**バーナム効果・確証バイアス**を統合解釈で使うのは歓迎する（占いとの付き合い方そのものの啓蒙になる）。
- 許可リストの主な概念: 自己効力感（バンデューラ）、統制の所在（ロッター）、自己決定理論（デシとライアン）、愛着スタイル、フロー（チクセントミハイ）、成長マインドセット（ドゥエック）、認知の再構成、行動活性化、実行意図＝if-thenプランニング（ゴルヴィツァー）、自己成就予言（マートン）、バーナム効果、確証バイアス、VIAの強み（ピーターソンとセリグマン）、心理的安全性（エドモンドソン）、境界（バウンダリー）設定、習慣ループ、レジリエンス、マインドフルネス、内発的動機づけ、損失回避、メンタル・アカウンティング（セイラー）、現在バイアス、計画錯誤、社会的比較、認知的不協和、セルフ・コンパッション（ネフ）、自己開示、ジョブ・クラフティング、意図的練習、アサーション、単純接触効果、感情のラベリング、拡張―形成理論（フレドリクソン）。全文と定義は `uranai/psych.py`。
- 概念を追加するときは、**名前のある確立した概念**であることを確かめ、由来（提唱者）は一般に定着しているものだけを書く。不確かなら由来は空にする。

## 4. 自己申告との照合

- 性格の自己申告（決断スタイル・お金・ストレス対処・恋愛傾向・自由記述）と占術の傾向を照合する（AMENDMENT_01 §4 から継続）。
- `integration.self_report_link` で、一致点とギャップを**否定せず両面として**描き、`integration.concepts` の概念と結びつける。
  - 例: 「相談して決める」と答えたあなたの習慣は、カードの「孤立」への対処そのものです（心理的安全性）。

## 5. 禁止事項（`check_style` で機械的に検査）

| 禁止 | 理由 | 検出の例 |
|---|---|---|
| 出典・数値の捏造 | 実在しない論文タイトル・著者・年・数値を作らない | 「研究によると68%が」「8割の人が」「2019年の研究で」「論文」 |
| 診断めいた言い方 | 用語は啓蒙のための教育的な使用に限る | 「〜障害」「〜症候群」「診断」「ADHD」 |
| タイプの断定 | 「傾向」「スタイル」の水準で書く | 「あなたは回避型です」 |
| 二層構造の重複 | 固定文が1回だけ出す | 「フレーム」 |

- 数値的な主張は、確立した一般知見の範囲に留める（「心理学では〜と考えられています」の水準）。
- 従来の鑑定作法（calc にない値を書かない、時刻不明は断定しない、矛盾は併記、断定予言や医療・法律・投資の助言をしない、第三者を鑑定しない、個人情報を書き写さない）はそのまま有効（`SYSTEM_PROMPT_BASE` の1〜11）。

## 5-2. 実用的な助言と本人の言葉（AMENDMENT_09 §B・§D）

- 回答（answer）と各テーマの④一歩は、本人の悩み・自由記入（question / worries / self_desc / about_me）・性格回答の**具体的な言葉を引き受けて**書く。言い換えではなく、本人の状況に置いた助言にする。
- 一歩は実行可能な粒度まで落とす：いつ／どのくらいの頻度で／誰に／何と言うか のいずれかを含める。「前向きに」「自分を信じて」等の精神論で終わらせない。
- 自由記入が空なら concern_theme と性格回答から焦点を作り、`focus_note` にその旨を書く（断定を弱める）。
- 機械検査（`psych.check_grounding`）：
  - 回答セクションに、question / worries から抽出した特徴語（漢字・カタカナ・英数字の2字以上の連なり。汎用語は除外）が1つ以上
  - 予言詩のモチーフ（§5-4。旧「本人の言葉3か所以上・逐語」ルールは**廃止**）
  - 一歩の具体性（時刻・回数・曜日・相手・「」の台詞などの具体形）と精神論の検出
  - 不合格なら理由を添えて1回だけ再生成。それでも駄目なら理由を qa.md に記録して描画（止めない）。※予言詩の助言調・災厄の断定（§5-4）は別検査で、こちらは描画を止める
- 追加の禁止パターン（`check_style`、不合格は再生成）：投資の断定的指示（「この銘柄は買いましょう」等）、医療的判断（「薬はやめて大丈夫」等）。

## 5-3. ケルティッククロス

- タロットはケルティッククロス10枚（1 現状／2 課題（交差）／3 土台／4 過去／5 目標・可能性／6 近未来／7 自分の立場／8 周囲と環境／9 願望と恐れ／10 結論）。`tarot_cross` に位置ごとの一言（本人の悩みに結びつける。カード名の列挙は不可）。占う対象は question → concern_theme → 全体運。

## 5-4. 予言詩（2ページ目・BRIEF §4）

2ページ目は、「天使の自動筆記」がその人のために書き留めた**予言詩**。抽象的・文学的・意味深に、象徴と暗示で近い未来を告げる。
（HUNTER×HUNTER の自動筆記の予言詩に着想を得たファンパロディ。原作の詩句は引用・模倣せず、文体の方針と見本はすべてオリジナル。）

### 形
- 四行連を基本に4〜7連（スキーマ上は3〜8連）。`poem.stanzas` の1要素が1連、連の中の行は改行で区切る。
- 合計 600〜900字（改行を除く）、合計32行以内、1行は12〜34字（検査上限40字）。予言めいたタイトル（16字以内）。
- 連ごとに時の目印（月の満ち欠け・季節・序数「三つ目の新月」など）を置き、これから起こることを順に暗示する。暦の日付・期限は断定しない。最後の連は成就の情景と余韻で閉じる。
- 中心の象徴は seed テーマ（`calc.json` の `poem.theme`。24候補は予言のイメージ: 欠けた月／七つ目の扉／砂時計／錆びた鍵／灰色の鳥／北の星／水底の鐘／霧の橋／白い羽根／燃える手紙／逆さの塔／潮目／眠る種／古い地図／鏡の向こう／夜明けの鐘／銀の糸／日蝕／迷い蝶／閉じた窓／風見鶏／三つの灯／冬の扉／夜の書架。SHA-256(seed + ':poem-theme') mod 24 で決定的）。

### モチーフ（入力と占術は「引用」ではなく「象徴」で織り込む）
- 本人の入力と占術結果から2〜5個を選び、象徴に置き換える。例: 悩みの「後輩」→「軒下の若い燕」、「資格の勉強」→「まだ読まれぬ頁」、タロット結論のカップの3 →「三つの杯」、五行で水が多い →「満ちてくる潮」。
- 本人の言葉をそのまま引用しない。名前を差し替えても成立する汎用詩は不可。
- 生成側は `poem.motifs` に `{source, origin, symbol}` を申告する:
  - `source`: `input.question` / `input.worries` / `input.self_desc` / `input.about_me` / `input.concern_theme` / `input.personality.decision|money|stress|love`、または `calc.<占術ID>`（`calc.tarot.spread[9]` のように細かくてもよい。たどれない部分は寛容に無視してサブツリー全体で探す）
  - `origin`: その出どころにある元の語・値（そのままの表記）
  - `symbol`: 置き換えた象徴の語（詩の本文に同じ表記で出る）
- **機械検査（`psych.check_poem_motifs`。soft）**:
  - 有効なモチーフ（source が実在・非空、origin が source のテキストに実在、symbol が本文に出る）が **2つ以上**、うち本人の入力由来が1つ以上（本人の入力が全て空なら calc 由来だけでよい）
  - 本人の自由記入（question / worries / self_desc / about_me）から **12字以上の逐語一致**が無い
  - 字数 540〜960（目安 600〜900）、3連以上・合計32行以内、1行40字以内
  - 不合格なら理由を添えて1回だけ再生成。それでも駄目なら理由を qa.md に記録して描画（止めない）。

### 禁止（hard。`psych.check_poem_literary`＝助言調＋`check_poem_doom`）
- **詩は文学であって助言ではない（AMENDMENT_16 を継続）**。実用的な助言・行動提案は1ページ目（回答・④一歩）だけの担当。
  - 命令・勧告・勧誘（〜しなさい／〜すべき／〜しよう／〜しましょう／〜してみて／〜てください／〜すればいい）、**託宣調の命令（〜せよ／気をつけよ／恐れるな）**
  - 教訓・まとめ（大切なのは／忘れずに／心がけ）、行動提案（〜として一歩／まずは〜）、読者への励まし・許可・祈り（あなたなら大丈夫／急がなくていい／〜ますように）
  - 「あなた」は描写の主語には使ってよいが、働きかけには使わない。正規表現リスト `POEM_ADVICE_PATTERNS`＋二人称文の `POEM_SECOND_PERSON_ADVICE`。本人の入力にそのまま実在する「」内の引用は対象外。
- **不吉さは象徴に留める**: 欠ける月・沈む鐘・灰色の鳥・閉じかけた扉のような翳りと曖昧さは文学表現として許容する。ただし死・事故・病気・災害・破産・離婚・失業などを本人に起きる出来事として**断定する直接表現**（「死ぬ」「事故に遭う」「病に倒れる」「破産する」等）は禁止（`POEM_DOOM_PATTERNS`）。「死神の札」のような象徴は対象外。
- 数値の主張・捏造引用・診断的表現（`FORBIDDEN`）は詩でも禁止（`check_style` が title・stanzas を検査。`motifs.origin/source` は入力の写しなので対象外）。
- 検出されたら理由（該当文つき）を添えて1回だけ再生成。それでも残れば**描画せず**、理由を qa.md に書いてジョブを失敗にする（1ページ目だけの鑑定書は出さない）。hard 不合格の詩は接地検査の fallback にも使わない。
- 占いは文化的・象徴的な読み物（エンターテインメント）であり確定的な予言ではない旨の注意書きは、従来どおり鑑定書・report.md に固定文で出す（詩の中には書かない）。

### 組版（p2）
- `digital.html.j2` の `#poem-body` は連＝段落、行＝ブロック（長い行はぶら下げ字下げで折り返し）。連のかたまりはページ中央に寄せ、行頭はそろえる。
- `fit.POEM_LEVELS` W0（10.6pt）〜W6（8.2pt）で、文字サイズ・行間・連間・本文開始位置だけを詰める（詩は削らない）。典型（4〜6連×4行）は W0〜W2、7連×4行は W4 前後、上限（8連×4行・900字）は W5 で収まることを確認済み。

### MCP サーバーから使う（単独生成）
- `reading.build_poem_prompt(job, calc) -> (system_prompt, user_prompt)`、出力スキーマは `reading.poem_schema()`。
- 検査は `psych.check_poem(poem, job, calc) -> {"hard": [...], "soft": [...], "motifs": {...}, "ok": bool}`。hard があれば1回だけ出し直し、残れば不採用。

## 6. A4 1枚との両立

- 情報量を増やすのではなく、文章を濃くする。字数の目安はスキーマの description にあり、短縮版（`print_*`・`*_print`）は特に厳守する。
- 印刷版・デジタル版は「同じ鑑定内容の2つのスキン」。どちらにも、占術の結果／4テーマの4層／統合解釈（一致・ずれ・自己申告照合・総評・固定文）／回答の4層／気をつけたいこと が載る。
  - デジタル版は、収まる限り全文（①②③④を別々の行）で出す。
  - 印刷版は短縮版を使い、③は②の短縮版（`print_lens`）に統合して出す。
- 収まらないときは `uranai/fit.py` の段階（文字サイズ→字数→要約）で詰める。縦に伸ばして逃げない。
